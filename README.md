# TaskFlow - تطبيق إدارة المهام 

تطبيق ويب احترافي ومتكامل لإدارة المهام تم تطويره باستخدام PHP وقاعدة بيانات MySQL (باستخدام PDO)، لمساعدة المستخدمين على تنظيم وترتيب أولويات مهامهم اليومية بكفاءة عالية.

## المميزات الرئيسية
- **نظام مصادقة آمن:** تسجيل حساب جديد وتسجيل دخول آمن للمستخدمين مع تشفير كلمات المرور (`password_hash`).
- **إعمليات CRUD الكاملة:** إضافة، عرض، تعديل (عبر نوافذ منبثقة تفاعلية Bootstrap Modals)، وحذف المهام بسلاسة.
- **لوحة إحصائيات وشريط تقدم:** لوحة تحليلية فورية تعرض إجمالي المهام، المنجزة، قيد التنفيذ، وقيد الانتظار، مدعومة بشريط تقدم مرئي متحرك.
- **بحث وتصفية متقدمة:** تصفية المهام فوراً حسب الحالة والأولوية، إلى جانب البحث النصي اللحظي.
- **تنبيهات المهام المتأخرة:** تنبيهات بصرية وشارات آلية للمهام التي تجاوزت تاريخ استحقاقها.
- **دعم الوضع المظلم (Dark Mode):** إمكانية التبديل السلس بين الوضعين الفاتح والداكن مع حفظ تفضيل المستخدم في المتصفح (`LocalStorage`).
- **واجهة عصرية ومتجاوبة:** مصممة بالكامل باستخدام **Bootstrap 5** لتوفير تجربة مستخدم مريحة وسريعة على مختلف الأجهزة.

## التقنيات المستخدمة
- **الخلفية (Back-End):** PHP, MySQL (PDO)
- **الواجهة الأمامية (Front-End):** Bootstrap 5, HTML5, CSS3, JavaScript
- **الأيقونات:** Bootstrap Icons

## التشغيل والتثبيت محلياً
1. قم بنسخ أو تحميل مجلد المشروع داخل مسار `htdocs` في برنامج XAMPP.
2. أنشئ قاعدة بيانات جديدة باسم `taskflow_db` عبر لوحة phpMyAdmin وقم استيراد هيكل قاعدة البيانات.
3. شغل المشروع في متصفحك عبر الرابط التالي:
   ```text
   http://localhost/taskflow/login.php
